Why Should a Developer or DevOps Engineer Learn Linux?
Linux is a critical skill for developers and DevOps engineers, offering a competitive edge in today’s tech landscape. Below are the key reasons to master Linux:
•	Backbone of IT Infrastructure: Linux powers the majority of modern servers, cloud platforms, and development environments.
•	Dominance in Servers: Most web servers, application servers, and databases run on Linux due to its reliability and scalability.
•	DevOps Tool Compatibility: Popular tools like Docker, Kubernetes, Ansible, Terraform, and Jenkins are designed to integrate seamlessly with Linux.
•	Cloud Integration: Major cloud providers (AWS, Azure, GCP) rely heavily on Linux-based virtual machines (VMs) and services.
•	Enhanced Security: Linux is inherently secure, reducing the need for third-party antivirus software.
•	Performance: Linux offers superior performance for resource-intensive tasks, making it ideal for development and production environments.

Introduction to the Linux Operating System (OS)
Linux is a powerful, open-source operating system with unique characteristics:
•	Community-Driven: Not owned by a single company, Linux is developed and maintained by a global community.
•	Free and Open-Source: Users can freely access, modify, and distribute its source code for customization.
•	Highly Secure: Built-in security features minimize vulnerabilities and eliminate the need for antivirus tools.
•	CLI-Based: The Command Line Interface (CLI) provides precise and powerful control over the system.
•	Enterprise-Friendly: Widely adopted by businesses for efficient server management and scalable solutions.

A Brief History of Linux
Linux has an inspiring origin story:
•	Creator: Developed by Linus Torvalds in 1991.
•	Motivation: Torvalds sought to overcome the limitations of Unix, a popular OS at the time.
•	Inspiration: He based Linux on Minix, a lightweight Unix-like OS, modifying its code to suit his vision.
•	Naming: The name "Linux" combines "Linus" and "Minix" (Li + nux = Linux).
•	Open-Source Legacy: Torvalds released the source code to the public, sparking widespread adoption and innovation.

Linux Distributions (Distros)
Linux’s open-source nature allows companies and communities to create tailored versions called distributions (distros). Examples include:

How to Set Up a Linux Machine
You can start using Linux through one of these three approaches:
Approach 1: Install Linux Directly on Your System
1.	Download a Linux distro (e.g., Ubuntu, Fedora, Debian).
2.	Create a bootable USB drive using tools like Rufus or Etcher.
3.	Boot from the USB and install Linux as your primary OS.
Approach 2: Run Linux in a Virtual Machine (VM)
1.	Install virtualization software like Oracle VirtualBox or VMware Workstation.
2.	Create a new VM and allocate resources (CPU, RAM, storage).
3.	Install your chosen Linux distro as a guest OS.

Mastering Linux Commands
Linux’s CLI is its powerhouse. Below are essential commands grouped by function:
Basic System Commands
•	whoami: Displays the current logged-in user.
•	pwd: Shows the present working directory (e.g., /home/user).
•	date: Prints the current date and time.
•	cal: Displays the current month’s calendar.
•	cal 2025: Shows the full calendar for 2025.
•	clear: Clears the terminal screen.
Directory Management
•	mkdir <name>: Creates a new directory (e.g., mkdir s3).
•	rmdir <name>: Removes an empty directory (e.g., rmdir qa).
•	rm -rf <name>: Deletes a non-empty directory and its contents (e.g., rm -rf devops).
•	cd <name>: Changes to a specified directory (e.g., cd s3).
•	cd ..: Moves up one directory level.
File Management
•	touch <filename>: Creates an empty file (e.g., touch t1.txt).
•	rm <filename>: Deletes a file (e.g., rm t1.txt).
•	mv <source> <destination>: Moves or renames a file/directory (e.g., mv t1.txt t2.txt).
•	cp <source> <destination>: Copies a file (e.g., cp t1.txt t2.txt).
File Viewing and Editing
•	cat > <filename>: Creates a file and adds data (press Ctrl+D to save).
•	cat >> <filename>: Appends data to an existing file.
•	cat <filename>: Displays file content (e.g., cat t1.txt).
•	cat -n <filename>: Shows content with line numbers.
•	tac <filename>: Displays content in reverse order (bottom to top).
•	head <filename>: Shows the first 10 lines (default). 
o	head -n 20 <filename>: Shows the first 20 lines.
•	tail <filename>: Shows the last 10 lines (default). 
o	tail -n 25 <filename>: Shows the last 25 lines.
o	Use Case: Monitor real-time logs with tail.
Searching and Filtering
•	grep 'keyword' <filename>: Searches for a keyword (e.g., grep 'hello' test.txt). 
o	-i: Case-insensitive search.
o	-n: Shows line numbers with matches.
o	-v: Displays lines without the keyword.
o	grep 'hello' *: Searches all files in the current directory.
o	tail test.txt | grep 'hello': Combines with tail for real-time filtering.
File Statistics
•	wc <filename>: Counts lines, words, and characters. 
o	-l: Counts lines only.
o	-w: Counts words only.
o	-c: Counts characters only.

Text Editors in Linux
The vi Editor
•	Overview: Default text editor in Linux, operates in three modes.
•	Modes: 
1.	Command Mode: Default mode when opening a file (vi <filename>).
2.	Insert Mode: Press i to edit text.
3.	Escape Mode: Press Esc to exit insert mode.
•	Commands: 
o	:wq: Save changes and exit.
o	:q!: Exit without saving.
Note: If the file doesn’t exist, vi creates it automatically.

The sed Command (Stream Editor)
Overview
•	Purpose: Processes text (substitute, delete, print, insert) without opening files.
•	Power: A versatile tool for automation and scripting.
Substituting Text
•	sed 's/old/new/' <filename>: Replaces the first occurrence.
•	sed 's/old/new/2' <filename>: Replaces the second occurrence.
•	sed 's/old/new/g' <filename>: Replaces all occurrences.
•	sed -i 's/old/new/g' <filename>: Saves changes to the file.
Deleting Lines
•	sed -i '1d' <filename>: Deletes the first line.
•	sed -i '4d' <filename>: Deletes the fourth line.
•	sed -i '$d' <filename>: Deletes the last line.
•	sed -i '5,15d' <filename>: Deletes lines 5 to 15.
Printing Lines
•	sed -n '10,20p' <filename>: Prints lines 10 to 20.
Inserting Text
•	sed '2i\text' <filename>: Inserts "text" at line 2.
•	sed '$a\text' <filename>: Appends "text" to the last line.

User Management in Linux
Key Concepts
•	Multi-User System: Supports multiple users working simultaneously.
•	Default User: In Amazon Linux VMs, the default user is ec2-user with sudo privileges.
•	Home Directories: Each user gets a home directory (e.g., /home/mike).
Commands
•	sudo useradd <username>: Creates a new user.
•	sudo passwd <username>: Sets/updates a user’s password.
•	cat /etc/passwd: Lists all users.
•	su <username>: Switches to another user.
•	cd ~: Navigates to the current user’s home directory.
•	sudo userdel <username>: Deletes a user.
•	sudo userdel --remove <username>: Deletes a user and their home directory.
•	sudo usermod -l <new-name> <old-name>: Renames a user.

Important Files
•	/etc/passwd: Stores user information.
•	/etc/shadow: Stores encrypted passwords.

Managing User Groups in Linux
Why Use Groups?
•	Efficiency: Assign permissions (read, write, execute) to a group instead of individual users.
•	Example: A "developers" group can access code repositories, while "finance" accesses reports.
Commands
•	cat /etc/group: Lists all groups.
•	sudo groupadd <group-name>: Creates a new group.
•	sudo usermod -aG <group-name> <username>: Adds a user to a group.
•	sudo gpasswd -d <username> <group-name>: Removes a user from a group.
•	getent group <group-name>: Lists users in a group.
•	id <username>: Shows a user’s groups.
•	sudo groupdel <group-name>: Deletes a group.
•	sudo groupmod -n <new-name> <old-name>: Renames a group.
